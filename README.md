# Waymo Incident Monitoring Dashboard

Cloud-native autonomous vehicle incident monitoring dashboard built using Microsoft Azure and Azure Static Web Apps.

## Project Overview

This project simulates operational monitoring for autonomous vehicle incidents in Nashville, TN. Incident telemetry data is visualized through a cloud-hosted dashboard using Azure services and JavaScript.

## Technologies Used

- Microsoft Azure
- Azure Static Web Apps
- Azure Table Storage
- Azure Logic Apps
- JavaScript
- HTML/CSS
- GitHub Actions
- Google Sheets API integration

## Features

- Real-time incident dashboard
- Vehicle monitoring KPIs
- Severity tracking
- Traffic blocking event simulation
- Operational telemetry visualization

## Key Learnings

- Cloud-native monitoring architecture
- Azure deployment workflows
- Static web app hosting
- Incident telemetry pipelines
- Dashboard visualization concepts

## Architecture

Logic App
↓
Azure Table Storage
↓
Google Sheets Integration
↓
Azure Static Web App Dashboard
